## ✦ التشغيل محليًا

### المتطلبات

* Node.js
* npm

### تثبيت الاعتماديات

```bash
npm install
```

### إعداد مفتاح Gemini

ضع قيمة `GEMINI_API_KEY` داخل ملف:

```text
.env.local
```

### تشغيل المشروع

```bash
npm run dev
```
